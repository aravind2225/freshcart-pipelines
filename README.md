# Iris Mage workflow

Start the Mage server and open the workflow UI from the repository root:

```powershell
.\.venv\Scripts\python.exe iris_project\main.py
```

The Iris workflow opens at
[http://localhost:6789/pipelines/iris_classifier](http://localhost:6789/pipelines/iris_classifier).
Its graph is defined in `iris_project\pipelines\iris_classifier\metadata.yaml`.
